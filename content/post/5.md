# Getting Started with Astro and Content Collections

Astro's content collections provide a powerful way to organize and validate your markdown content. In this post, I'll walk through setting up collections for a portfolio site.

## Why Use Content Collections?

- **Type safety** with Zod schemas
- **Automatic routing** and pagination
- **Easy querying** via the `getCollection()` API

## Step-by-Step Setup

1. Define your collections in `src/content/config.ts`
2. Create markdown files with frontmatter matching the schema
3. Use `Astro.glob` or `getCollection` to render content

## Example Code

```astro
---
import { getCollection } from 'astro:content';
const posts = await getCollection('post');
---
<ul>
  {posts.map(post => <li>{post.data.title}</li>)}
</ul>
