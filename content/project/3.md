# My Awesome Project

This project was built to solve the problem of habit tracking in a fun and interactive way.  
It includes a RESTful API, a responsive frontend, and real-time data visualization.

## Features

- User authentication with JWT
- Habit creation, completion, and streak tracking
- Weekly progress charts
- Dark mode support

## Tech Stack

- Frontend: React + Vite + Tailwind CSS
- Backend: Node.js + Express + MongoDB
- Deployment: Docker + AWS
